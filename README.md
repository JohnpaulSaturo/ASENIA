# QR-ID Attendance Monitoring System

Static HTML prototype for Carlos P. Garcia Senior High School.

## Deploy to Vercel
- Set Framework Preset to Other.
- Leave Build Command blank.
- Set Output Directory to `.` if required.
- Deploy this folder.

The website uses the supplied `wallpaper.mp4` video as a full-screen, autoplaying, muted, looping live wallpaper behind every page. Keep `wallpaper.mp4` in the same folder as `index.html` when deploying. The music player remains separate.
